# TaskFlow

TaskFlow is a responsive task management web app built with HTML, CSS, and JavaScript.

## Features

- Create, edit, and delete tasks
- Set task priority (`High`, `Medium`, `Low`)
- Set optional due dates
- Track task status (`To Do`, `In Progress`, `Done`)
- Search by title/description
- Filter by status and priority
- Dashboard statistics for all statuses
- Offline persistence with LocalStorage

Open `/home/runner/work/TaskFlow/TaskFlow/index.html` in your browser.
